# Decode Stage

## Overview

The Decode Stage is responsible for interpreting the fetched instruction and preparing all information required by the Execute Stage.

Its primary responsibilities are:

* Instruction field extraction
* Instruction classification
* Control signal generation
* Register operand retrieval
* Immediate generation
* Pipeline state propagation

Pipeline flow:

```text
Instruction
      ↓
Instruction Splitter
      ↓
Instruction Decoder
      ↓
Main Control Unit
      ↓
Register File
      ↓
Immediate Generator
      ↓
ID/EX Register
```

---

# Inputs

From the IF/ID pipeline register:

| Signal      | Width |
| ----------- | ----- |
| PC          | 32    |
| Instruction | 32    |
| Valid Bit   | 1     |

# Implemented Components

## Instruction Splitter

The Instruction Splitter extracts all standard RV32I instruction fields from the 32-bit instruction word.

### Outputs

| Field  | Bits    |
| ------ | ------- |
| opcode | [6:0]   |
| rd     | [11:7]  |
| funct3 | [14:12] |
| rs1    | [19:15] |
| rs2    | [24:20] |
| funct7 | [31:25] |

### Design Rationale

Instruction fields are extracted once and distributed to all decode-stage modules, reducing duplicate wiring and simplifying circuit organization.

---

## Instruction Decoder

The Instruction Decoder performs opcode classification.

Unlike a traditional flat opcode decoder, this implementation uses a hierarchical classification approach.

### Classification Method

#### Stage 1

Opcode bits 5 and 6 are decoded to broadly classify instruction families.

#### Stage 2

Demultiplexers further refine instruction groups using opcode bits 2 and 4.

#### Stage 3

Remaining ambiguities are resolved using opcode bit 3.

### Generated Instruction Classes

The decoder produces one-hot instruction-class outputs:

```text
LOAD
STORE
BRANCH
OP
OP_IMM
LUI
AUIPC
JAL
JALR
SYSTEM
MISC_MEM
```

### Architectural Decision

Instruction classification and control generation are intentionally separated.

The Instruction Decoder identifies the instruction class, while the Main Control Unit generates processor control signals.

Benefits:

* Reduced logic complexity
* Easier debugging
* Clear separation of responsibilities
* Improved scalability

---

## Register File

The Register File implements the architectural RV32I register set.

### Configuration

```text
32 Registers
32 Bits Per Register
```

### Ports

```text
2 Read Ports
1 Write Port
```

### Special Register

```text
x0 = 0
```

Register x0 is permanently hardwired to zero and ignores all write attempts.

### Outputs

```text
rs1_data
rs2_data
```

These values are forwarded to the Execute Stage through the ID/EX register.

---

## Immediate Generator

The Immediate Generator reconstructs RV32I immediates and produces a 32-bit sign-extended result.

### Inputs

```text
instruction[31:0]
ImmSel
```

### Output

```text
immediate[31:0]
```

### Supported Formats

```text
I-Type
S-Type
B-Type
U-Type
J-Type
```

The immediate format is selected using the ImmSel control signal generated by the Main Control Unit.

---

## Main Control Unit

The Main Control Unit generates all processor control signals required by later pipeline stages.

### Inputs

```text
Instruction Class Signals
funct3
funct7
```

### Generated Control Signals

| Signal       | Purpose                   |
| ------------ | ------------------------- |
| RegWrite     | Register write enable     |
| MemWrite     | Memory write enable       |
| MemRead      | Memory read enable        |
| Branch       | Branch operation          |
| ALUSrc       | ALU operand source select |
| ALUOp        | ALU operation category    |
| ImmSel       | Immediate format select   |
| WritebackSel | Writeback source select   |

These control signals are stored inside the ID/EX pipeline register and travel with the instruction through the pipeline.

---

## ID/EX Pipeline Register

The ID/EX register forms the boundary between the Decode and Execute stages.

### Stored Operand Data

```text
PC
rs1_data
rs2_data
immediate
```

### Stored Register Metadata

```text
rd
rs1
rs2
```

### Stored Instruction Metadata

```text
funct3
funct7
```

### Stored Control Signals

```text
RegWrite
MemWrite
MemRead
Branch
ALUSrc
ALUOp
ImmSel
WritebackSel
```

### Stored Pipeline Metadata

```text
valid_bit
```

---

# Outputs

The Decode Stage outputs:

* Register operands
* Immediate values
* Register identifiers
* Instruction metadata
* Control signals
* Pipeline validity information

to the Execute Stage through the ID/EX pipeline register.

---

# Current Status

The Decode Stage is fully implemented for RV32I instruction decoding, operand preparation, immediate generation, control generation, and pipeline state propagation.

Future work primarily involves hazard handling, CSR support, and branch-specific decode optimizations.
