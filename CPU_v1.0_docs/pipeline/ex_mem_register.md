**Document Version:** v1.0

**Last Updated:** YYYY-MM-DD

**Status:** Draft

---

# 1. Overview

The EX/MEM pipeline register separates the Execute (EX) stage from the Memory Access (MEM) stage.

It captures the results generated by the Execute stage at the rising edge of the clock and forwards them to the Memory stage in the following cycle.

The register stores:

- execution results
- branch information
- destination register metadata
- memory control signals
- write-back control signals

---

# 2. Purpose

The EX/MEM register provides:

- stage isolation between EX and MEM
- synchronized pipeline execution
- temporary storage of ALU results
- branch decision propagation
- memory control propagation
- write-back control propagation

```text
posedge(CLK)

↓

Capture inputs

↓

Update outputs
```

---

# 9. Reset Behavior

When reset is asserted:

```text
valid_out = 0

PC_out = 0

ALU_Result_out = 0

branch_taken_out = 0

RegWrite_out = 0

MemWrite_out = 0

MemRead_out = 0
```

---

# 10. Memory Stage Interface

The Memory stage consumes:

- ALU_Result_out
- rs2_data_out
- MemRead_out
- MemWrite_out

The Writeback stage later consumes:

- RegWrite_out
- WritebackSel_out
- rd_out
